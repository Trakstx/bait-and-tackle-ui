# Release notes

## v0.6.0 — Public preview

- Bait & Tackle skin with vertical native bag columns and C/X controls at the top.
- DPS strip with automatic character-log switching and fight history.
- Complete Heal announcement parser and floating timer strip.
- One themed Ctrl+J HTML panel for DPS and CH settings, with Aggro settings reserved for later.
- Private Python/Tk runtime and a backup-producing installer.

Known limits: CH timers are predictions based on announcements; raid validation is pending. Exclusive fullscreen is unsupported for the CH overlay. Threat estimates are partial. Bag capacities remain handled by native bag windows, not an unrestricted 80-slot inventory grid. Automatic update checks are not yet implemented.
